Published at the 2024 Conference on Empirical Methods in Natural Language Processing (EMNLP), this work examines the structural basis of truthfulness in large language models, identifying a universal truthfulness hyperplane that spans model representations. The project's GitHub code repository is Universal_Truthfulness_Hyperplane.
